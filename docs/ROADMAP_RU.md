# Состояние KeybindBridge

## Уже реализовано

- внутриигровой MyGUI по `End`; внешний Win32-интерфейс при FeatureLevel 8 не
  открывается;
- автономная загрузка расширений через `keybindbridge.json`, без установки
  активационного блока;
- общий список автономных функций модов, переназначение и сохранение клавиш;
- простой API `registerAction` и обёртка `KeybindAction` для мододелов;
- отдельные локальные бинды Keybind Logic, отсутствующие в общем меню и хотбаре
  сиденья;
- проверка конкретного сиденья, защита пассажиров и сброс нажатий вне сиденья;
- отдельный Mode Controller для HOLD/TOGGLE/PULSE;
- восстановление runtime после выхода и повторного входа в мир;
- автономный фонарик как отдельный мод с узким `spotLight`, размещённым движком
  на кости головы персонажа.

## Стабильная основа 1.0.0

- собственный направленный `spotLight` без ambient-дымки `FluorescentLight`;
- engine-host на `jnt_head` без покадрового обновления мирового transform;
- точное направление по `sm.camera.getDirection()` через обновляемые локальные
  offsets: вертикаль не замирает, быстрый поворот не оставляет луч позади;
- вынос 0.005/0.07 в первом лице и 0.10/0.07 в третьем;
- источник первого лица остаётся на jnt_head ради динамических теней;
- присед компенсируется только вертикальной дельтой высоты глаз, без переноса
  spotLight непосредственно в камеру;
- синхронное закрытие MyGUI и runtime через `Esc` без потери бинда;
- effect-set перенесён в sandbox основного мода; при недоступности имени один
  раз выбирается направленный встроенный `HeadLight`;
- автоматическое выключение и блокировка фонарика в сиденье или кровати;
- подавление автономных действий, пока открыто меню биндов;
- корректные коды Mode Controller в допустимом диапазоне power `-1..1`;
- точные штатные эффекты `Button - On` / `Button - Off` через
  `sm.effect.playEffect` у позиции персонажа без верхней надписи;
- очередь и повтор звука после callback без world-контекста.

## Возможные следующие версии

- привести внешний вид меню ближе к ванильным настройкам Scrap Mechanic, не
  теряя блокировку управления игрой при открытом окне;
- добавить нормальную локализацию названий и подсказок меню;
- при необходимости добавить мышиные кнопки интерфейса, сохранив управление
  клавиатурой;
- поддерживать английскую и русскую документацию синхронно;
- развивать на этом API отдельные моды: карта, рюкзаки и другие автономные
  действия с собственной сетевой логикой;
- позже добавить систему экипировки с отдельными слотами/меню: фонарик, броня,
  патронаши и другие модули должны регистрировать бинд только после получения
  или экипировки соответствующего предмета.
