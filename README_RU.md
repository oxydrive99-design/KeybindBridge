# KeybindBridge 1.0.0

KeybindBridge добавляет Scrap Mechanic общий API дополнительных клавиш для
Lua-модов. Мододел объявляет действие с постоянным ID, названием и клавишей по
умолчанию, а игрок может переназначить его во внутриигровом меню по `End`.

Проект состоит из независимых частей:

- `keybind_bridge.dll` — считывает клавиатуру и мышь, хранит назначения и
  публикует `sm.keybind` в Lua;
- `KeybindBridge Core` — запускает автономные расширения, содержит меню биндов,
  блок Keybind Logic и Mode Controller;
- `KeybindBridge Flashlight` — необязательный пример настоящего автономного
  мода без активационного блока;
- SDK — готовый шаблон, короткие примеры и справочник API.

## Возможности 1.0.0

- клавиши `A–Z`, цифры, служебные клавиши, `F1–F24` и пять кнопок мыши;
- единое меню автономных действий по `End`;
- сохранение назначений между мирами и перезапусками;
- несколько действий на одной клавише и несколько слушателей одного действия;
- события нажатия, отпускания и состояние удержания;
- автоматический поиск `keybindbridge.json` в локальных и Workshop-модах;
- работа автономного мода без размещения блока в мире;
- подавление игровых действий во время настройки биндов без их последующего
  повторного срабатывания;
- отдельный Keybind Logic для конкретного водительского или пассажирского
  сиденья, не занимающий слот хотбара;
- режимы блока `HOLD`, `TOGGLE`, `PULSE`;
- отдельный Mode Controller, переключаемый клавишей, `U` или обычным логическим
  сигналом;
- серверная проверка конкретного подключённого сиденья;
- отсутствие жёстких смещений функций внутри `ScrapMechanic.exe`.

## Требования

- Windows x64;
- Scrap Mechanic;
- совместимый DLL-инжектор, загружающий модули из `Release/DLLModules`;
- DLL должна быть установлена каждому игроку, который нажимает собственные
  дополнительные клавиши.

## Установка для игрока

1. Из Windows-архива скопируй `keybind_bridge.dll` и
   `KeybindBridge.diagnostics.ini` в:

   `Steam/steamapps/common/Scrap Mechanic/Release/DLLModules`

2. Из архива модов скопируй `KeybindBridge-Core` в каталог локальных модов:

   `%APPDATA%/Axolot Games/Scrap Mechanic/User/User_<id>/Mods`

3. По желанию туда же скопируй `KeybindBridge-Flashlight`.
4. Включи моды при создании или редактировании мира.
5. Полностью перезапусти Scrap Mechanic после добавления или удаления
   автономного мода.

Штатный `FeatureLevel` — `8`. Уровни `0–7` предназначены только для диагностики
проблем запуска.

## Меню биндов

Нажми `End` в мире:

- `↑/↓` — выбрать действие;
- `Enter` — назначить новую клавишу;
- `Delete` — вернуть клавишу по умолчанию;
- `Esc` или `End` — закрыть меню.

Назначение сохраняется сразу в
`Release/DLLModules/KeybindBridge.bindings.ini`. В меню появляются только
автономные действия модов. Бинды отдельных блоков туда намеренно не выводятся.

## Блоки

### Keybind Logic

1. Подключи к синему блоку конкретное сиденье.
2. Нажми `E` на блоке и затем желаемую клавишу.
3. Нажимай `U`, чтобы выбрать `HOLD → TOGGLE → PULSE`.
4. Подключи выход к логике, лампе, контроллеру, bearing или другому совместимому
   потребителю.

Блок реагирует только на игрока в подключённом сиденье. Для пассажира нужен
отдельный Keybind Logic, подключённый к его креслу. Нажатия вне сиденья
поглощаются и не воспроизводятся после посадки.

### Mode Controller

Оранжевый блок меняет режим подключённых Keybind Logic. Его можно переключить:

- передним фронтом обычной кнопки, затвора или сенсора;
- вручную клавишей `U`;
- назначенной клавишей из подключённого сиденья.

Один Mode Controller может управлять несколькими блоками.

## Самый короткий автономный мод

Положи рядом с `description.json` файл `keybindbridge.json`:

```json
{
  "version": 1,
  "script": "Scripts/KeybindBridgeExtension.lua"
}
```

Содержимое `Scripts/KeybindBridgeExtension.lua`:

```lua
local ACTION = "yourname.yourmod.open_map"

local extension = {
    id = "yourname.yourmod.map_extension",
    actions = {
        {
            id = ACTION,
            label = "Open map",
            defaultKey = "M"
        }
    }
}

function extension:onActionPressed(actionId)
    if actionId == ACTION then
        self:openMap()
    end
end

KeybindBridgeRuntime.registerExtension(extension)
```

ID расширения и действий должны быть постоянными и глобально уникальными.
Используй префикс автора и мода. Изменение ID сбрасывает сохранённое назначение
и создаёт новую строку в меню.

Полностью готовая структура лежит в `examples/sdk-template-mod`. Руководство с
примерами нажатия, удержания и безопасного сетевого действия находится в
`docs/MODDERS_GUIDE_RU.md`, полный список функций — в `docs/API.md`.

## Важно для мультиплеера

Клавиша является только локальным пользовательским вводом. Клиент не должен
самостоятельно выдавать предметы, менять серверный контейнер или состояние
мира. Отправляй запрос через `self.network:sendToServer(...)`, а на сервере
повторно проверяй игрока, расстояние, владельца, экипировку и допустимость
операции. Пример находится в
`examples/snippets/03_existing_script_with_helper.lua`.

## Сборка DLL

Требуется Visual Studio 2022 с компонентом разработки классических приложений
на C++.

1. Открой `native/KeybindBridge.sln`.
2. Выбери `Release | x64`.
3. Собери решение.
4. DLL появится в `native/x64/Release/keybind_bridge.dll`.

Отдельная установка LuaJIT и vcpkg не нужна. MinHook включён в исходники и
содержит собственную лицензию. GitHub Actions автоматически выполняет эту
сборку и создаёт релизные архивы для тегов `v*`.

## Логи и диагностика

Лог DLL: `Release/DLLModules/KeybindBridge.log`.

Нормальный запуск содержит:

```text
OK: discovered ... autonomous extension manifest(s)
OK: core KeybindRuntime.lua source loaded from disk
OK: KeybindBridge 1.0.0 initialized; FeatureLevel=8
OK: KeybindBridge client runtime started
```

Если игра вылетает, используй уровни из `docs/DIAGNOSTICS_RU.md` и прикладывай
отдельный `KeybindBridge.log` и игровой `game-*.log` для каждого теста.
