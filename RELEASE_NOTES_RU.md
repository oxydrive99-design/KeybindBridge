# KeybindBridge 1.0.0

Первый стабильный релиз моста дополнительных клавиш для Scrap Mechanic.

## Для игроков

- общее меню биндов по `End`;
- назначения сохраняются между мирами;
- поддерживаются клавиатура и пять кнопок мыши;
- Keybind Logic управляет любыми совместимыми выходами из конкретного сиденья;
- отдельный Mode Controller переключает Hold/Toggle/Pulse;
- опциональный автономный фонарик работает без активационного блока.

## Для мододелов

- регистрация действия через `registerAction(id, label, defaultKey)`;
- автоматические расширения через `keybindbridge.json`;
- press/release/hold API;
- `KeybindAction.lua` для существующих scripted-object скриптов;
- готовый устанавливаемый шаблон и примеры сетевой проверки.

## Установка

Архивы разделены намеренно:

- `Windows-x64` содержит только DLL и конфигурацию;
- `Mods` содержит основной мод и фонарик;
- `SDK` содержит документацию и примеры.

Смотри `INSTALL_RU.txt` или `README_RU.md`.

## Известные ограничения

- только Windows x64;
- требуется сторонний DLL-инжектор;
- интерфейс меню управляется клавиатурой;
- все игроки, использующие дополнительные клавиши, устанавливают DLL локально;
- KeybindBridge передаёт ввод, но серверную синхронизацию инвентарей и других
  игровых систем обязан реализовать сам мод.
