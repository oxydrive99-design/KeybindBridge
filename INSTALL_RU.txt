KeybindBridge 1.0.0 — установка
================================

1. Установить совместимый SM DLL Injector.

2. Из архива KeybindBridge-1.0.0-Windows-x64.zip скопировать
   keybind_bridge.dll в:
   Steam/steamapps/common/Scrap Mechanic/Release/DLLModules

3. Из KeybindBridge-1.0.0-Mods.zip скопировать папку KeybindBridge-Core в:
   %APPDATA%/Axolot Games/Scrap Mechanic/User/User_<id>/Mods

4. По желанию туда же скопировать KeybindBridge-Flashlight.

5. Включить моды в мире и полностью перезапустить Scrap Mechanic.

6. В мире нажать End. В меню:
   Up/Down  — выбор
   Enter    — переназначить
   Delete   — вернуть по умолчанию
   Esc/End  — закрыть

Файл диагностики не обязателен. Без KeybindBridge.diagnostics.ini DLL
автоматически использует полный FeatureLevel=8. Создавай файл рядом с DLL
только для диагностики или разработки плагина.

Лог DLL:
Steam/steamapps/common/Scrap Mechanic/Release/DLLModules/KeybindBridge.log

При каждом запуске игры лог автоматически создаётся заново.

Каждому игроку, использующему дополнительные клавиши, нужна DLL локально.
