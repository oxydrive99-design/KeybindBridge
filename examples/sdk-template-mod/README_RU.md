# Готовый шаблон автономного мода

Этот мод запускается KeybindBridge автоматически, без установки блока. После
его включения в меню `End` появятся две функции:

- `SDK example: press` — одиночное нажатие `K`;
- `SDK example: hold` — удержание `H` и отпускание.

Перед созданием собственного мода:

1. Сгенерируй новый UUID и замени `localId` в `description.json`.
2. Переименуй мод в `description.json`.
3. Во всём `Scripts/KeybindBridgeExtension.lua` замени префикс
   `example.keybindbridge` на уникальный префикс автора и мода.
4. Измени названия действий, клавиши по умолчанию и содержимое callback-функций.
5. Не меняй путь в `keybindbridge.json`, если имя Lua-файла осталось прежним.

На верхнем уровне Lua-файла оставляй только объявления и
`KeybindBridgeRuntime.registerExtension(extension)`. Игровые вызовы выполняй в
`onCreate`, `onActionPressed` или `onUpdate`.

Для интерфейса, фонарика и других чисто клиентских функций этого достаточно.
Для изменения серверного инвентаря, контейнеров или мира используй действие из
обычного scripted-object/player/tool скрипта и отправляй запрос через
`self.network` с обязательной серверной проверкой.
